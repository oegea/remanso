# Decisiones de producto (ADR)

Aquí queda constancia de las decisiones de producto y de diseño de Remanso, con su
contexto, la evidencia en la que se apoyan y dónde están implementadas. Es el
complemento de la base científica: `docs/research/` dice qué sabe la investigación;
estos documentos dicen qué decidió Remanso con ello y por qué.

| Documento | Contenido |
|---|---|
| `registro-de-decisiones.md` | Registro cronológico de decisiones (ADR-001 en adelante): contexto, decisión, evidencia, dónde |
| `../research/design-decisions.md` | Trazabilidad principio → decisión → evidencia → código, para la versión de terminal |
| `../architecture/donde-se-lee-cada-dato.md` | Cada dato que se introduce y la pantalla donde se lee |
| `../../web/DESIGN.md` | Sistema de diseño de la versión web (color, tipografía, movimiento, componentes) |

Regla que rige todas las decisiones: **prima la evidencia científica**. Una preferencia de
diseño o un comentario de uso no puede contradecir lo que la investigación revisada
establece; cuando hay tensión, se documenta aquí cómo se resolvió.
