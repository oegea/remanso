# Voz guía de Meditar

Los archivos de esta carpeta son las frases que guían la sesión de meditación, generadas con
el modelo abierto Qwen3-TTS (Alibaba, licencia Apache 2.0, voces «Serena» y «Ryan») a partir
de los textos de `src/audio/voice-lines.json`, con el guion `tools/gen_voice.py`.
